# Stage reports

The study ran in stages, with a stop and a written report after each one. Each report was reviewed before the next stage ran. The rulings from each review are logged in `DECISIONS.md` at the repo root, and every change made after the first results is in `DEVIATIONS.md`.

| Stage | Report |
|---|---|
| 0. Data check | `REPORT_DATA.md` |
| 1. First full run | `REPORT_RESULTS.md` |
| 2. Checks, round 1 | `REPORT_CHECKS.md` |
| 3. Checks, round 2 | `REPORT_CHECKS_2.md` |
| 4. Checks, round 3 | `REPORT_CHECKS_3.md` |

The reports are kept as they were written, so some of them refer to files at the repo root that now sit in this folder.
